Freshness is checked again against the train's advanced base immediately before every landing.

## Known gap

Rebinding proves that the rebased head is the one checked and merged, but it does not prove that a clean three-way rebase left the seat-owned hunk semantically unchanged. A textual conflict stops the train; a clean rebase that changes the hunk's result remains exposed. The next task closes that gap.
