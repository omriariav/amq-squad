# t61d: proof-backed merge-train rebind

Before re-binding an updated PR, the train compares `git patch-id --stable` for the seat's range at the old and new heads. A mismatch is refused before the binding write or merge. A matching proof is recorded on the rebind journal entry, and a later run can finish a journaled binding write whose server head still matches. Dry runs state that this proof will run; their binding read (`store.Get`) may complete an earlier committed store transaction but writes nothing of its own.
