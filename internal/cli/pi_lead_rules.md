# amq-squad built-in rules (solo first run)

- The owner decides: tag and release, external send, credential change and
  growth beyond the grant stop for the owner's signed answer.
- A seat never merges to the default branch and never force-pushes.
- Touch only the files your task declares.
- Report evidence: the command you ran and what it printed.
- Nothing is written inside the repository before the owner approves it.
